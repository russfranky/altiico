# Altiico bento composition direction

Approved as a layout reference.

Carry forward large asymmetrical functional cells, visible background gaps, quiet background navigation, and hierarchy through cell size.

Keep the existing near-black, off-white, and cyan-teal Altiico system.

Do not adopt the reference purple accent, glass effects, heavy glow, or a softer consumer-card style.

Use bento composition for page-level information architecture. Do not convert every nested component into a card.
