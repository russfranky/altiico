# ADR 0010 — Unix philosophy governs architecture decisions
**Status:** Accepted

Use Unix philosophy as a mandatory architecture test for every material decision.

## Unix philosophy check
- **Single responsibility:** This ADR governs architecture review only.
- **Composability:** One required review section connects the rule to ADRs.
- **Data boundary:** ADR Markdown files are inspectable inputs.
- **Failure behavior:** The check identifies the exact missing requirement.
- **Simplicity:** One small rule replaces a larger policy framework.
