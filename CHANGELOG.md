# Changelog

All notable changes to Altiico Catalog will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). The project follows Semantic Versioning where practical during the pre-1.0 period.

## [Unreleased]

### Added

- Repository governance, security, support, contribution, architecture, development, and release documentation.
- Deterministic repository verification and project status commands.
- Baseline CI, CodeQL, dependency review, and Dependabot configuration.
- Issue and pull request templates.

### Changed

- Public and repository-facing language now distinguishes Altiico Catalog from the downstream Hubzz Altiico product.
- The public catalog uses consistent Altiico branding and an explicit alpha maturity statement.

### Security

- Added a private vulnerability reporting policy and least-privilege workflow guidance.
