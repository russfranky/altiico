How This Pipeline Reduces File Size

  • Cel Shading Baking: Pre-renders toon lighting into diffuse texture, eliminating runtime shader complexity
  • Texture Atlas: Combines all materials into single 1024x1024 texture, reducing draw calls and memory
  • Ambient Occlusion Baking: Multiplies AO into base color, removes separate AO map (saves 1-2MB)
  • Mesh Decimation: Reduces polygon count to 7000 faces (VRM platform standard) using edge collapse
  • DRACO Compression: Compresses geometry with KHR_draco_mesh_compression (3-6x mesh size reduction)
  • Mesh Quantization (KHR_mesh_quantization): Stores vertex positions/normals/UVs as 16-bit or 8-bit integers instead of 32-bit floats (50% vertex buffer reduction)
  • WebP Texture Format (EXT_texture_webp): Converts PNG textures to WebP with 26-35% smaller file size vs PNG/JPEG, lossless quality
  • Bone Reduction: Removes unused armature bones (hair/skirt physics bones not animated) - reduces skinning CPU cost and file size
  • BlendShape Pruning: Removes morph targets with zero-weight or duplicate data (common in VRoid exports), compresses remaining with sparse accessors
  • Expected Result: 70-85% file size reduction (17MB → 2.5-5MB typical), 2-3x faster load times, preserved visual style
