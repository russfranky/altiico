# Support

Altiico Catalog is an alpha-stage open-source research project.

## Questions and usage help

Before opening an issue:

1. read [README.md](README.md) and [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md);
2. run `make verify` to check the local repository state;
3. search existing issues for the error or collection name;
4. confirm whether the problem affects committed data, a live third-party source, or the public deployment.

Use the bug report template for reproducible defects. Use the feature request template for product or pipeline proposals.

## Data corrections

A correction request should identify the exact chain, contract, token, collection ID, or source URL and include primary evidence where possible. Similar names or related project branding are not enough to merge identities.

## Security

Do not use a public support issue for vulnerabilities or exposed credentials. Follow [SECURITY.md](SECURITY.md).

## Service expectations

The public catalog and third-party source integrations are provided without a service-level agreement. External APIs, gateways, project websites, and marketplace data can become unavailable or change without notice.
